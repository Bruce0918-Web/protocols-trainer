# Protocols 训练器

帮我把《Protocols》里对我有用的做法做一辈子:每天回顾执行情况,自己写出每条背后的机制,定期筛选。

## 怎么用

- **每天早上**:打开“记录”页,把前一天过一遍。默认都算做到,点掉没做到的,打三个分,保存。
- **读完一部分后**:在电脑上改 `content/` 里的文件(见下),推送后手机上就是新内容。
- **换手机或清浏览器之前**:到“备份”页导出 JSON。

## 内容文件

| 文件 | 内容 |
| --- | --- |
| `content/school.yaml` | 校历:哪天上学、哪个轮换日。现在排到 2027-02-12,之后要补。 |
| `content/parts.yaml` | 书的 7 个部分。读完一部分就把 `read` 改成 `true`。 |
| `content/systems.yaml` | 7 张底层系统卡。先写这些。 |
| `content/protocols.yaml` | 每条 protocol 一张卡。机制链、变通、证据都由我自己写。 |

一张卡写完机制链四格、填了页码、开卷核对过,才把 `checked` 改成 `true`。

## 命令

```
npm run dev            本机预览 (http://localhost:5183)
npm run lint:content   检查内容文件有没有写错
npm test               跑测试
npm run build          检查 + 构建到 dist/
```

## 进度

- 阶段 1(已完成):内容文件和校验、每日回顾、卡片浏览、导出导入。
- 阶段 2:复习(间隔重复、六种题型、训练期 / 维持期)和讲解页。
- 阶段 3:进度页、系统地图、季度评审。
